# Software Architecture — 2026-II (Section 3)

Course repository for the software architecture project. Each team owns one directory
and works only inside it.

Team directories follow the `g3-<X>-<Name>` naming convention. If a team changes
its directory name, update this table in the same Pull Request. Each team's README
contains its members, architecture, and local setup instructions.

## Working agreement

- `main` is protected. Every change lands through a Pull Request approved by @ssuarezs.
- Work only inside your own team directory. Do not touch another team's files.
- Name your branch `g3-<X>/<short-description>`, for example `g3-A/api-gateway`.
- Keep your team README current: members, project, architecture, and how to run it.
