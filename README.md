## Working agreement

- `main` is protected. Every change lands through a Pull Request approved by @ssuarezs.
- Work only inside your own team directory. Do not touch another team's files.
- Name your branch `g3-<X>/<short-description>`, for example `g3-A/api-gateway`.
- Keep your team README current: members, project, architecture, and how to run it.
