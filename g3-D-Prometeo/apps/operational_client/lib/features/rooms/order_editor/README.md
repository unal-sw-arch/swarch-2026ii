# Partes del editor de pedido

- `selected_items`: resumen y edición de unidades seleccionadas.
- `catalog_browser`: navegación y búsqueda del catálogo.
- `product_customization`: ingredientes, notas y productos especiales.
- `draft_submission`: undo, agrupación y envío.
- Los demás archivos contienen modelos y widgets privados del editor.
